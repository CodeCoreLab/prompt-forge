Prompt Forge v1.1.4 - 轻量本地版
================================

使用步骤
--------
1. 双击 PromptForge.exe
2. 程序启动本地 HTTP 服务（默认 127.0.0.1:8787）并自动打开浏览器界面
   若端口被占用，会自动顺延到下一个可用端口，并在窗口给出醒目告警；
   实际地址以 "LISTENING http://..." 一行为准
3. 在界面「设置」里新建模型配置（协议 / Base URL / 模型名 / API Key），点「测试连接」
4. 输入原始想法，选模式 / 增强方式 / 思考强度 / 角色，点「增强」

命令行参数
----------
  --port <端口>     监听端口（默认 8787）
                    端口被占用时默认自动顺延到下一个可用端口（最多试探 20 个），
                    并在 stderr 告警、stdout 输出 LISTENING <实际地址> 行
  --strict-port     严格模式：端口被占用时直接报错退出（退出码 1），不顺延
                    适用于端口被防火墙规则 / 书签 / 自动化脚本固定的场景
  --no-browser       启动后不自动打开浏览器
  --web-dir <目录>   指定前端资源目录

说明
----
- 单文件 1.6MB，零第三方 DLL，仅依赖 Windows 系统自带库
- API Key 经 Windows DPAPI 加密后只存本机配置文件，无明文落盘
- 无遥测、无账号、无云端同步，调用大模型的数据直接发往你配置的地址
- 停止服务：在任务管理器结束 PromptForge.exe
