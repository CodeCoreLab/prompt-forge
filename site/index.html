什么场景用它

凡是「要给 AI 下任务」的时刻，都值得先过一遍 Prompt Forge。

写 Prompt 没手感

知道想要什么但说不清楚——丢一句口语化需求进来，拿走结构完整的任务书。

多模型来回切

DeepSeek 写方案、Claude 改代码、本地 Ollama 处理敏感文本——一套界面管理所有配置，切换只改下拉框。

团队提示词规范化

用自定义模式沉淀团队风格：code review 模板、周报模板、测试用例模板——一次定义，全组复用。

给另一个会话备料

把增强好的提示词一键复制，粘到任意 AI 对话框直接使用——工具只产出提示词，不绑定任何平台。

三步上手

下载解压 → 填一个模型配置 → 开始增强。

下载并解压

取回 PromptForge-Setup.exe，双击安装。或使用便携版 PromptForge-Portable.exe 直接运行。无需安装 WebView2 或其他运行时。

配置一个模型

设置 → 新建配置：选协议（如 OpenAI 兼容）、填 Base URL（如 https://api.deepseek.com）、模型名和 API Key。点「测试连接」确认。

输入一句，点增强

左侧输入原始想法，选模式，点「增强」。结果可一键复制；不满意可点「取消」中断，或从历史里回填继续迭代。

FAQ

需要联网吗？我的 Key 会被上传吗？

调用你配置的大模型需要联网，但除此之外无任何外部请求——没有遥测、没有账号体系。API Key 经 Windows DPAPI 加密后只存本机配置文件。

和网页版提示词工具比有什么区别？

三件事：① 模型配置完全自持，不受平台模型列表限制；② 托盘常驻 + 开机自启，随时唤起；③ 单文件离线分发，内网环境也能用本地 Ollama。

增强结果会带「以下是优化后的内容」这类废话吗？

不会。输出纪律写进模板最高优先级：只输出提示词本体，禁前后缀、禁解释、禁代码块包裹；运行时还会再剥一层围栏和引号兜底。

为什么我的自定义模式里不写语言规则也能中英对应？

extend 型自定义模式自动继承内置「保真与语言规则」（语言跟随、语义等价、防编造），你只需要写策略差异部分。

源码在哪？ License 是什么？
